## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Paddock must check what crosses between the sandbox and an A2UI tab without linking A2UI (it does not build on Linux). Deep validation stays in A2UI's PayloadValidator on the Mac; PaddockCore holds only Paddock's own limits and the media rule that the Mac never fetches an agent-chosen URL.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A2UI JSONL from the sandbox is split into messages with caps per line, per tab and in total; an oversized or non-JSON line is refused with a reason, without dropping the valid ones
- [ ] #2 Only v1.0 messages naming the basic catalog id are accepted; others are refused with a reason the agent sees
- [ ] #3 Renderer-to-agent messages are size-checked before they reach the sandbox
- [ ] #4 A media reference resolves to exactly one of: fetch in the sandbox (http/https), read a sandbox file (relative path, no escape from the tab folder), decode on the Mac (data:, size-capped); any other scheme is refused
- [ ] #5 sbx exec arguments for sending, waiting and fetching are built in one place; JSON never carries secrets
- [ ] #6 Every rule is covered by fixture-based tests that pass under mise run test on Linux
<!-- AC:END -->

## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The macOS-only layer that links A2UI (a2ui-project/a2ui pinned exactly to v0.12.0+swift) and turns the PaddockCore transport into a live surface. One MessageProcessor per tab, owned by the view model, keeps typed values across tab switches. Image, Video and AudioPlayer are replaced so media only arrives through the sandbox; openUrl goes to a sandbox browser tab.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Packages/PaddockA2UI builds on macOS only and PaddockCore does not depend on it; Linux mise run test is unaffected
- [x] #2 A2UITab (@MainActor @Observable) feeds checked messages to MessageProcessor and hands every outbound message to the transport
- [x] #3 The Paddock catalog keeps the v1.0 basic catalog id and every basic component and function, with Image, Video and AudioPlayer loading through a MediaSource that never fetches from the Mac
- [x] #4 openUrl reaches a handler that asks for a sandbox browser tab and opens nothing on the Mac
- [x] #5 The agent-function timeout is long enough for an agent in a terminal, and a waiting call is visible in the tab
- [x] #6 Mac tests render the fixtures and check outbound messages; mise run test runs them on the Mac
- [x] #7 On the Mac, mise run capture:a2ui is rerun (pluralize examples included), and renderer/library-calls.jsonl holds the callAgentFunction and rendererFunctionResponse messages as the library emits them

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Packages/PaddockA2UI (macOS only, like PaddockShellUI): PaddockCore by path and a2ui exactly 0.12.0 (tag v0.12.0+swift). 2. A2UITabLink: the tab's way to the sandbox (deliver a line, media bytes for a sandbox source, open a URL in the sandbox's browser), implemented by the app with A2UICommands. 3. A2UITab (@MainActor @Observable): its A2UIInbox, one MessageProcessor with the Paddock catalog, surfaces in arrival order, every outbound message through A2UIPolicy.lineForAgent and the link in order, agent function calls shown while waiting (timeout 10 min), a notice for each delivered action and opened link. 4. PaddockCatalog: the v1.0 basic catalog (same id, every component and function, locale of the Mac), Image/Video/AudioPlayer replaced by views loading through A2UIMediaStore (A2UIMedia sources, files in a per-tab temporary folder), openUrl to a handler that asks the link. 5. A2UITabView: surfaces in a scroll view, the notice, the waiting state. 6. Tests on the Mac from Fixtures/a2ui; mise run test runs the package on macOS; project.yml adds it.
<!-- SECTION:PLAN:END -->

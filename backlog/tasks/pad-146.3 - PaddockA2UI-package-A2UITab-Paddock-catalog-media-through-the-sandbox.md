## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The macOS-only layer that links A2UI (a2ui-project/a2ui pinned exactly to v0.12.0+swift) and turns the PaddockCore transport into a live surface. One MessageProcessor per tab, owned by the view model, keeps typed values across tab switches. Image, Video and AudioPlayer are replaced so media only arrives through the sandbox; openUrl goes to a sandbox browser tab.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 Packages/PaddockA2UI builds on macOS only and PaddockCore does not depend on it; Linux mise run test is unaffected
- [ ] #2 A2UITab (@MainActor @Observable) feeds checked messages to MessageProcessor and hands every outbound message to the transport
- [ ] #3 The Paddock catalog keeps the v1.0 basic catalog id and every basic component and function, with Image, Video and AudioPlayer loading through a MediaSource that never fetches from the Mac

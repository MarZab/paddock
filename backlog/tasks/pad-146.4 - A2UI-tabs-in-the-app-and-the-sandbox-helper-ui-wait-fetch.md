## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Wire A2UI tabs end to end: the agent opens and updates a tab, gets every renderer message back, and media and links go through the sandbox.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 paddock ui FILE|- opens an A2UI tab and prints its id; paddock ui ID FILE|- sends more messages to it
- [x] #2 paddock wait ID prints each renderer-to-agent message as one JSON line, unchanged, and Paddock events in their own shape
- [ ] #3 paddock --fetch fetches a media URL inside the sandbox (sbx rules apply) with a size cap; the tab shows a clear placeholder when it fails
- [ ] #4 openUrl after a click opens the page as a browser tab in the sandbox
- [ ] #5 The tab is marked by color like other interactive tabs and confirms each delivered action
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Sandbox helper (BrowserShow.script): paddock ui FILE|- opens an A2UI tab whose messages (a JSON array, {messages}, one object, or JSONL) are kept as a JSONL log; paddock ui ID FILE|- (and goto) appends; --messages ID OFFSET prints the log from OFFSET as base64; --operator ID a2ui takes one line on stdin (a tab message or a Paddock event) for paddock wait, which prints it as it is; --read ID PATH reads a file next to the tab's source; --fetch ID URL fetches http(s) with curl inside the sandbox and prints Content-Type, newline, base64. Node-run test. 2. SbxService.perform(_:stdin:); ProjectRunner: A2UI log read, deliver, fetch, read, open a URL as a sandbox tab, all through A2UICommands. 3. App: an A2UI tab per interactive show kept in ProjectTerminals (its A2UITab and an AppA2UILink), read on each revision from its offset, rebuilt from 0 on the operator's Refresh, disposed when the tab closes; A2UITabView replaces OpenUIView.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
Helper: paddock ui keeps the agent's messages as a JSONL log next to the record (a JSON array, {messages}, one object, or JSONL are all accepted, checked for JSON objects with version 1.0 and the size caps before a tab opens); ui ID FILE and goto append and bump the revision; reload and back are refused for the agent (the operator's Refresh redraws in Paddock and notes it); --operator ID a2ui takes the line on stdin; wait prints it as it is, and now starts from what the agent last saw (agentSeen), so a message that came before the call is not lost (for page tabs too: an earlier 'opened' prints at once); locked() releases the lock when fail() exits inside it. App: ProjectTerminals keeps an A2UITab per interactive show; AppModel.syncA2UI reads from the tab's offset at each revision, one read per tab at a time, and redraws from the first message on Refresh (A2UIShowView.swift, with AppA2UILink over ProjectRunner). OpenUIView is gone; OpenUIPolicy, the vendored bundle and the guide go in PAD-146.5. Not yet built: the app needs the Mac.

On the Mac (2026-11-24): the app builds and every test passes. Criteria 3 to 5 (a real fetch in a sandbox and its placeholder, openUrl opening a sandbox tab, the tab's color and confirmation in the running app) are checked live in PAD-146.6; the code paths are unit-tested (A2UIPolicyTests, A2UIHelperTests, A2UITabTests).
<!-- SECTION:NOTES:END -->

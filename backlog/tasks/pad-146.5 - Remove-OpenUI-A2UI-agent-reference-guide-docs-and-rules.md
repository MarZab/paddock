## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
The sandbox guide's example id tab-k3f9 is not one paddock makes (ids are tab- and four lowercase hex digits; found in PAD-146.2): use a valid one such as tab-a3f9 when the guide is rewritten.

The reference's example was rendered by A2UI's Swift core (tools/tasks/lib/a2ui-capture.swift) and its answer captured; a test checks the example passes A2UIInbox. The guide's ids are tab-a3f9 now (tab-k3f9 was never a valid id).

## Final Summary

OpenUI is gone: the vendored bundle and host page, vendor:openui, OpenUIPolicy/OpenUIMessage, the OpenUI event commands and helper events, the reference and its tests.

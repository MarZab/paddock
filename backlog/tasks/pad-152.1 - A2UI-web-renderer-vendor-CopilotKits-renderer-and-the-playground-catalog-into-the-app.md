## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Paddock needs a host page that renders A2UI messages with CopilotKit's Gen UI 2.0 renderer and the playground's 121-component catalog, built from pinned sources (the playground's MIT source and published @copilotkit/* packages), offline.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 mise run vendor:a2ui-web builds App/A2UI from a pinned CopilotKit commit and pnpm lockfile (install-time analytics and telemetry off), with the licenses, the version, and a manifest of every file
- [x] #2 The host page renders A2UI 1.0 messages given as data (window.paddockA2UI.render), one surface per surfaceId, and reports ready, actions (as A2UI action messages) and problems through one message handler
- [x] #3 A headless browser check renders the fixtures (a Sankey among them) with every request outside the bundle blocked, and a click comes back as an action
<!-- AC:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. tools/tasks/vendor/a2ui-web.sh: sparse checkout of CopilotKit at a pinned commit (examples/showcases/a2ui-playground), pnpm install from its lockfile (analytics off), Vite added at exact versions. 2. tools/tasks/lib/a2ui-web: index.html (CSP: only its own origin), host.tsx (CopilotKit's surface renderer with playgroundUI, a page-local agent that receives each action, errorBoundary to A2UI errors), media.ts (image/video/audio/poster URLs to ./__media on its own origin, embeds as a link card), offline map style, next/dynamic shim, fewer Shiki grammars. 3. Output App/A2UI with VERSION, THIRD_PARTY_LICENSES.txt and manifest.json; fixtures from the playground's samples and catalog. 4. --check: headless Chromium, every other request blocked, buttons clicked, actions recorded.
<!-- SECTION:PLAN:END -->

## Implementation Notes

<!-- SECTION:NOTES:BEGIN -->
All 10 fixture files (108 surfaces) render offline with no request outside the bundle and no error; maps draw markers and routes on the offline style; remote images go to ./__media; embeds show a link card. 19 MB (host.js 4.1 MB, 1.2 MB gzip; lazy chunks for code grammars, Mermaid, MapLibre). Locale data is not bundled: formatting uses the browser's Intl (the Mac's language). Chromium for --check: Debian's chromium (Playwright's CDN downloads came out truncated in the sandbox).

The operator asked (2026-11-25) to keep every code grammar: the Shiki pruning is gone; 24 MB, 441 files; still lazily loaded.
<!-- SECTION:NOTES:END -->

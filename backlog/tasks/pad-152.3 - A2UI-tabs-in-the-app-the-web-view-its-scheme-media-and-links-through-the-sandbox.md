## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The app shows an interactive tab as the vendored host page in a locked-down web view and connects it to the sandbox through PaddockCore.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 A web view per interactive tab, kept while hidden: no stored data, content rules blocking everything but its own scheme, only the manifest's files, no new windows
- [x] #2 Accepted messages go to the page as data at each revision; actions and problems come back through one checked handler and reach paddock wait in order
- [x] #3 Images, video and audio in the page load through the sandbox (a fetch there, or a file next to the messages); links open as a sandbox browser tab or a native tab; nothing loads from the network on the Mac
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
The app draws an interactive tab as the vendored A2UI page in a locked-down web view (App/A2UIViews.swift). Everything decidable without WebKit is in PaddockCore's A2UIWebPolicy, tested on Linux against the shipped manifest and fixtures: scheme paddock-a2ui://app/, only the manifest's files, __media/<kind>/<base64url> read back into the URL a component named, HTTP byte ranges for video, content rules, the render script (all messages as one JSON string), what a clicked link means, and A2UIWebMessage, which checks what the page posts (ready, action, error, problem). A2UIWebTab (one per tab, kept in ProjectTerminals while hidden, disposed when the tab closes, its show goes, Refresh, or the sandbox stops) owns the web view: it reads the log through A2UIInbox at each revision (AppModel.syncA2UI, one read at a time), tells the agent about refused lines, delivers actions and A2UI errors to paddock wait in order, loads media through the sandbox (kept per tab for range requests), and opens links as a sandbox browser tab or a native tab. The host page now applies only new messages and leaves a surface without news alone; the headless check renders each fixture in two reads (all 108 surfaces ok, offline). vendor:a2ui-web reruns now (pnpm purge without a TTY, store for licenses). Not yet compiled on the Mac: PAD-152.5.
<!-- SECTION:FINAL_SUMMARY:END -->

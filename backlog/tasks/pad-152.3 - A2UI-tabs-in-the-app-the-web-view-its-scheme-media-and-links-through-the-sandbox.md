## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The app shows an interactive tab as the vendored host page in a locked-down web view and connects it to the sandbox through PaddockCore.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [ ] #1 A web view per interactive tab, kept while hidden: no stored data, content rules blocking everything but its own scheme, only the manifest's files, no new windows
- [ ] #2 Accepted messages go to the page as data at each revision; actions and problems come back through one checked handler and reach paddock wait in order
- [ ] #3 Images, video and audio in the page load through the sandbox (a fetch there, or a file next to the messages); links open as a sandbox browser tab or a native tab; nothing loads from the network on the Mac
<!-- AC:END -->

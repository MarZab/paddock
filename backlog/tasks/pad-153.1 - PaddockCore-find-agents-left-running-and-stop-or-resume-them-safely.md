## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Paddock needs to tell an agent it left running (its tab is one this app opened and no longer has) from one another Paddock runs (Paddock Dev and the installed Paddock share sandboxes and the data folder) or one started outside Paddock, and to stop a sandbox process without killing a reused pid.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Paddock keeps the tab ids it opened per project, per app (bundle id), in its data folder; a session is left running only when its tab is one of them, not open now, and its process is known
- [x] #2 Stopping a session runs one sbx exec that ends the process only if its environment still has that session's PADDOCK_TAB (TERM, then KILL after a grace period); stopping any sandbox process checks its pid still has the same name
- [x] #3 Taking over builds sbx run --name N -- --resume ID for a Claude session id that is a UUID, and --continue otherwise; nothing from the sandbox reaches argv unchecked
- [x] #4 Fixture-based tests cover each rule
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
LeftAgents finds the agents this app left running: the status kit's session names a tab this app opened (OpenedTabs, kept per project and per bundle id in <data folder>/tabs/<bundle id>.json, so Paddock Dev and the installed Paddock leave each other's agents alone), the tab is not open, and the process is known. stopCommand runs one sbx exec whose script ends the pid only while its environment still has that PADDOCK_TAB (stopProcessCommand: while its comm is the same name), TERM then KILL after a grace (zombies count as ended); pid 1 is refused. resumeArguments passes --resume with Claude's session id only when it is a UUID, else --continue. ProjectRunner.stopLeftAgent and stopSandboxProcess, and SandboxShellSession's agentArguments (sbx run --name N ... -- ARGS). Tests use two real sessions from a sandbox as a fixture and run the stop script for real on Linux. Limit: the kit's watcher forgets a session file untouched for a day.
<!-- SECTION:FINAL_SUMMARY:END -->

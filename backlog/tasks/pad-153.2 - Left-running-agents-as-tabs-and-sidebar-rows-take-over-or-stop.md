## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The operator should see an agent Paddock left running where they see agents: as a tab and a sidebar row, and act on it.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Each left-running agent shows as a tab in its project (and a sidebar row that selects it), with its state and how long
- [x] #2 Opening the tab explains it and offers Take Over (stop it, then a new agent tab resuming its session) and Stop; it warns when the agent is working
- [x] #3 Closing the tab stops the session; a session that ends on its own takes its tab with it
- [x] #4 Doc UI describes it; CHANGELOG line
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
Each agent this app left running (LeftAgents) shows as a host tab, 'claude (left running)', with its working or waiting mark, and as a sidebar row (SidebarAgents place leftRunning, SidebarSelection.leftAgent) that selects it. LeftAgentView explains it, shows its state and session id, warns while it works, and offers Take Over (stop, then an agent tab with sbx run --name N -- --resume ID) and Stop. Closing its tab stops it, and closing an agent or shell tab now stops the agents in it too (otherwise they would come back as left running); a tab being stopped goes at once and comes back if the stop failed. AppModel keeps OpenedTabs (loaded at start, pruned, saved on each new tab). Doc UI and CHANGELOG. Built and checked only on Linux (PaddockCore); the app needs a Mac build and a live check that sbx passes -- --resume ID to the agent.
<!-- SECTION:FINAL_SUMMARY:END -->

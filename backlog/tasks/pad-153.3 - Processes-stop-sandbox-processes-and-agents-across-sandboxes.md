## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
The project's Processes tab lists what runs in the sandbox but cannot stop anything, and there is no one place to see every agent in every running sandbox.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 The project's Processes tab stops a selected process after a confirmation (checked by pid and name)
- [x] #2 System > Processes has an Agents section: every agent session in every running sandbox with its project, state, and where it is (a tab, left running, or outside Paddock), with Stop, and Take Over for left-running ones
- [x] #3 Doc UI describes it; CHANGELOG line
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
The sandbox's Processes tab has Stop... in a process row's context menu: after a confirmation, ProjectRunner.stopSandboxProcess ends it only while its pid still has the same comm (never pid 1). System > Processes has an Agents in sandboxes table above the Mac's sbx processes: every agent session in every running sandbox with project, agent, state, where (LeftAgents.Place: in a tab, left running, another Paddock's tab, outside Paddock; tested), for how long, and session; its context menu shows the tab, takes a left-running agent over, and stops agents this Paddock opened after a confirmation. Doc UI and CHANGELOG. Not compiled on the Mac yet.
<!-- SECTION:FINAL_SUMMARY:END -->

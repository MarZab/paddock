## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Quitting Paddock leaves its agents running in their sandboxes with no terminal; the operator wants to know before that happens.
<!-- SECTION:DESCRIPTION:END -->

## Acceptance Criteria
<!-- AC:BEGIN -->
- [x] #1 Quitting while an agent tab's session runs asks first, naming the projects and how many agents (working ones called out), with Quit Anyway and Cancel
- [x] #2 Cancel keeps Paddock open; Quit Anyway quits as before, and the agents show as left running at the next launch
- [x] #3 Doc UI describes it; CHANGELOG line
<!-- AC:END -->

## Final Summary

<!-- SECTION:FINAL_SUMMARY:BEGIN -->
PaddockAppDelegate (NSApplicationDelegateAdaptor) asks in applicationShouldTerminate while any agent runs in Paddock's tabs (AppModel.runningAgents: agent tabs whose session has not exited, and shell tabs an agent reports from): QuitWarning.text names the projects, how many agents and how many working, and says they keep running and show as left running at the next launch (tested). Quit Anyway quits as before; Cancel keeps Paddock open. Doc UI and CHANGELOG. Not compiled on the Mac yet.

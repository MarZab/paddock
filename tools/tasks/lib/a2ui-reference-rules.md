# A2UI reference (for paddock ui)

`paddock ui` shows an interface you describe in A2UI v1.0 messages to the operator, in a tab next
to your terminal. Paddock draws it natively on their Mac from A2UI's basic catalog; it runs no code
of yours. Their clicks and form values come back to you through `paddock wait`.

## How Paddock runs it

- Write the messages to a file, one JSON object per line (JSONL), or as one JSON array of
  messages. `paddock ui form.jsonl --title "Deploy"` opens the tab and prints its id
  (`tab-` and four hex digits). `-` reads stdin.
- Change the tab later with more messages: `paddock ui tab-ID more.jsonl` (an `updateDataModel`,
  an `updateComponents`, a `deleteSurface`, an `agentFunctionResponse`). The tab keeps everything
  you sent before.
- Every message has `"version": "1.0"` and exactly one of `createSurface`, `updateComponents`,
  `updateDataModel`, `deleteSurface`, `callRendererFunction`, `agentFunctionResponse`.
- Every surface uses the basic catalog:
  `"catalogId": "https://a2ui.org/specification/v1_0/catalogs/basic/catalog.json"`. Nothing else
  is drawn.
- In `updateComponents`, the component with id `root` comes first, and parents before their
  children.
- At most 512 KB per message and 8 MB per tab; open a new tab past that.

## What comes back

`paddock wait tab-ID` prints, one JSON line each, what the tab sent since you last looked:

- `{"version":"1.0","action":{"name":...,"surfaceId":...,"sourceComponentId":...,"timestamp":...,"context":{...}}}`:
  a Button with an `event` action was pressed. `context` holds what you bound there with
  `{"@path": "/..."}`: that is how you get form values.
- `{"version":"1.0","error":{"code":...,"message":...,"surfaceId":...}}`: A2UI could not use one of
  your messages (`VALIDATION_FAILED` names a `path`), or a Button's `@checks` failed when it was
  pressed (the `path` is the button's id). Fix the messages and send them again.
- `{"version":"1.0","callAgentFunction":{"functionCallId":...,"callFunction":{...}}}`: a surface
  called a function the catalog does not have. Answer with an `agentFunctionResponse` of the same
  `functionCallId` (`value` or `error`); the tab waits for it up to 10 minutes.
- `{"version":"1.0","rendererFunctionResponse":{...}}`: the answer to your `callRendererFunction`.
- `{"paddock":"refused","line":N,"reason":...}`: Paddock did not draw line N of what you sent; the
  rest was drawn.

## Media and links

- Image, Video, and AudioPlayer take `https://` or `http://` URLs (fetched inside this sandbox,
  so its network rules apply), a path relative to the messages file (`shots/home.png`), or a
  `data:` URL. Each file at most 40 MB. Nothing else loads; the tab says why.
- `openUrl` (a Button's `functionCall`) opens an http(s) page as a tab of this sandbox's browser,
  which the operator sees in Paddock. Nothing opens on their Mac.

## Rules

- Never ask for passwords, keys, or tokens, even though TextField has an `obscured` variant: ask
  the operator to put secrets where they belong themselves.
- Tell the operator in one line what the tab is for (new tabs never take their focus).
